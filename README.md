# 🛍️ Jola

**Jola** — full-stack интернет-магазин с каталогом товаров, корзиной, оформлением заказов, онлайн-оплатой, админ-панелью и модулем полиграфии.

Проект построен на современном JavaScript-стеке: **React + Vite** на клиенте и **Node.js + Express + MongoDB** на сервере.

---

## ✨ Возможности

| Раздел | Что есть внутри |

| 🛒 Магазин | каталог, поиск, фильтры, сортировка, карточки товаров |

| 📦 Склад | остатки, списание после заказа, журнал изменений |

| 🖨️ Полиграфия | загрузка файлов, настройка печати, пересчёт стоимости |

| 🔔 Уведомления | Telegram и Email-уведомления о новых заказах |
| 🛡️ Защита | авторизация, защита заголовков, лимиты запросов и очистка входящих данных |

## 🚀 Быстрый запуск

### 1. Установить зависимости

```bash
cd server
npm install

cd ../client
npm install
```

### 2. Подготовить окружение

Создай файлы окружения на основе примеров:

```bash
cp server/.env.example server/.env
cp client/.env.example client/.env
```

Для локального запуска нужны адрес MongoDB, порт сервера, адрес клиента и ключ авторизации. Дополнительно можно подключить Stripe, Telegram и Email-уведомления.

### 3. Запустить backend

```bash
cd server
npm run dev
```

### 4. Запустить frontend

```bash
cd client
npm run dev
```

После запуска сайт будет доступен по адресу:

```txt
http://localhost:5173
```

## 🔌 Основные API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/products` | список товаров |
| GET | `/api/products/:id` | карточка товара |
| GET | `/api/categories` | список категорий |
| POST | `/api/categories` | создание категории |
| POST | `/api/orders` | оформление заказа |
| GET | `/api/orders` | список заказов пользователя или администратора |
| PUT | `/api/orders/:id/status` | обновление статуса заказа |
| POST | `/api/payments/stripe/webhook` | webhook Stripe |

## 🖨️ Полиграфия и редакторы

В проекте есть отдельный сценарий для печати:

- загрузка файлов;
- выбор параметров печати;
- автоматический пересчёт цены;
- отправка файла в заказ;
- редактирование PDF, DOCX и изображений в браузере.

Офисный редактор работает без отдельного OnlyOffice-backend.

## 🧪 Проверка перед деплоем

```bash
cd client
npm run build

cd ../server
npm test
```

Перед публикацией проверь:

- MongoDB доступна;
- файлы окружения заполнены;
- ключ авторизации заменён;
- Stripe webhook прописан в Dashboard;
- production URL указан в настройках сервера;
- загружаемые файлы не попадают в Git;
- секреты не лежат в репозитории.
